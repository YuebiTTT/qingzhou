# 轻舟

一个极简美观的浏览器起始页。

## 功能

- **实时时钟** - 显示当前时间、日期和星期
- **多搜索引擎** - 支持百度、Google、必应搜索
- **搜索联想** - 智能搜索建议，提升搜索效率
- **快捷方式** - 自定义网站快捷方式，点击即可跳转
- **每日一言** - 每天更换一句名言警句
- **随机壁纸** - 每次打开都是不同的壁纸，支持手动切换
- **响应式设计** - 适配各种屏幕尺寸
- **本地存储** - 所有设置保存在浏览器本地，无隐私担忧

## 使用方法

直接在浏览器中打开 `index.html` 文件，或将其设置为浏览器的新标签页。

## 自定义

### 快捷方式

1. 将鼠标移至页面底部显示快捷方式栏
2. 点击编辑按钮修改现有快捷方式
3. 点击"+"按钮添加新的快捷方式

### 搜索引擎

点击搜索框上方的标签切换不同的搜索引擎。

### 壁纸

点击右上角的"换壁纸"按钮可更换随机壁纸。

## 技术栈

- 纯 HTML + CSS + JavaScript，无任何外部依赖
- 毛玻璃效果（Glassmorphism）
- CSS 变量实现主题一致性
- LocalStorage 数据持久化
